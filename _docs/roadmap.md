# Roadmap

Что делаем сейчас (MVP) и что оставляем на Post-MVP.

---

## MVP (хакатон)

### Ядро механики

- [x] Страница входа с выбором роли
- [x] Регистрация по e-mail с подтверждением (прототип: любой 6-значный код)
- [x] Опрос: отрасль, специализация, предполагаемый грейд
- [x] Тест: генерация заданий через LLM, оценка, присвоение категории
- [x] Кабинет кандидата: категория, история, статус грейда
- [x] Кабинет работодателя: описание потребности, подборка
- [x] Приглашение с описанием и **вилкой зарплаты**
- [x] Статусы приглашений, раскрытие контактов при `accepted`
- [x] Настройки кандидата: приватность, согласия, ФСП ID
- [x] Админ-панель: управление новостями и анкетами

### ИИ

- [x] AI Service: `LlmProvider`, health-check, fallback
- [x] Генерация тестовых заданий через LLM (Ollama `llama3.1:8b`)
- [x] Fallback на пул эталонных заданий при недоступности LLM
- [ ] Оценка свободных ответов по рубрике через LLM
      (заглушка: 50 баллов, если ответ > 20 символов)
- [ ] Разбор свободного запроса работодателя → структурированный фильтр
- [ ] Ранжирование кандидатов через LLM с объяснением
      (сейчас — формула, LLM — Post-MVP)

### Инфраструктура

- [x] Docker + Docker Compose
- [x] Деплой-скрипты на VPS (`deploy.ps1`, `deploy_up.ps1`)
- [x] nginx в контейнере: статика + проксирование `/api/*`
- [x] PostgreSQL со схемой по сервисам
- [x] Миграции через `node-pg-migrate`
- [x] Туннель Ollama (WebSocket + HTTP-фасад)
- [ ] OpenAPI-спецификация (черновая, покрывает 3 эндпоинта из ~30)
- [ ] Метрики Prometheus (`/metrics`)
- [ ] Логи pino с correlation-id

### Документация

- [x] Архитектура и микросервисы
- [x] Экраны
- [x] Vision, roadmap, user-flows
- [x] Data-model, API, интеграции
- [x] Безопасность, 152-ФЗ
- [ ] Тестирование и валидация (процедуры описаны, чисел нет)
- [ ] Презентация и demo-script

## Post-MVP

### Продуктовые фичи

- [ ] Классический отклик кандидата на вакансию
- [ ] Публикация вакансий работодателем
- [ ] Регулярные короткие задания от работодателей
- [ ] Адаптивная мобильная вёрстка
- [ ] Чат между кандидатом и работодателем
- [ ] ИИ-помощник в чате

### ИИ

- [ ] Адаптивные тесты (CAT) — сложность подстраивается под ответы
- [ ] IRT-модель для калибровки заданий
- [ ] ML-ранжирование на истории приглашений
- [ ] Self-consistency для спорных оценок
- [ ] Реальная оценка свободных ответов через LLM

### Инфраструктура

- [ ] Message bus (RabbitMQ → Kafka)
- [ ] Redis как обязательный компонент (кеш промптов, очереди)
- [ ] S3 для файлов (MinIO в dev, Yandex Object Storage в проде)
- [ ] OpenTelemetry-трейсинг
- [ ] Prometheus + Grafana + алерты
- [ ] PgBouncer + read replica

### Интеграции

- [ ] Реальный API ФСП (когда откроют)
- [ ] Keycloak / ФСП ID
- [ ] ATS-коннекторы (Huntflow, Greenhouse)
- [ ] SMTP для уведомлений

### Микросервисы

- [ ] Вынос AI Service в отдельный процесс
- [ ] Вынос FSP Integration
- [ ] Вынос Test Service
- [ ] Вынос Matching Service
- [ ] Вынос Chat Service

Порядок и триггеры — см. [microservices.md § 14](./microservices.md).

---

## Что осознанно НЕ делаем в MVP

- Микросервисы — преждевременно, монолит быстрее итерации.
- PostgreSQL-кластер — одного инстанса хватит.
- Message bus — пока нечего асинхронизировать.
- Антифрод и модерация — вынесено в Post-MVP.
- Мобильное приложение — ТЗ говорит «опционально».
