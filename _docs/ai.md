# ИИ в архитектуре

Три точки входа LLM. Все — через AI Service, единый интерфейс.

## Точки входа

| Точка | Сервис | Что делает |
|---|---|---|
| Тестирование | Test | Генерация заданий, оценка ответов, скоринг |
| Подбор | Matching | Разбор запроса, ранжирование, объяснения |
| Чат | Chat | ИИ-помощник: вопросы кандидату |

## Абстракция `LlmProvider`

```js
interface LlmProvider {
  generateTest(params): Promise<TestTask>
  evaluateAnswer(params): Promise<Evaluation>
  parseQuery(params): Promise<StructuredFilter>
  rankCandidates(params): Promise<RankedList>
  suggestQuestions(params): Promise<Question[]>
}
```

Реализации:

- `YandexGptProvider` — российский, 152-ФЗ-совместим.
- `GigaChatProvider` — российский, аналогично.
- `OpenAiProvider` — только для обезличенных данных.
- `OllamaProvider` — локальный, для dev.

Переключение — `LLM_PROVIDER=yandex|giga|openai|ollama`.

## Экономика

- **Кеш промптов** в Redis. TTL 24 ч для генерации, 1 ч для ранжирования.
- **Квоты:** на пользователя (20 генераций/день) и на сервис (5000/день).
- **Батчинг:** где можно, объединять запросы (оценить все ответы кандидата
  одним вызовом).
- **Метрики:** `cost_per_user`, `cost_per_test`, `cost_per_match`.
- **Fallback:** при превышении бюджета — автоматический переход на пул задач
  и формульный скоринг.

## Безопасность

- **Prompt injection** — ввод только в отведённые слоты.
- **Анонимизация** — ПДн не уходят в LLM.
- **Аудит** — каждый вызов в `ai.llm_calls`.
- **Output filtering** — проверка на утечки.

| GigaChat | ✅ | низкая | средняя | Альтернатива |
