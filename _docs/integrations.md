# Внешние интеграции

## ФСП (Федерация спортивного программирования)

**Статус:** API не открыт, организаторы подтвердили — только Post-MVP.

**Что интегрируем:**
- достижения участника по ФСП ID (соревнование, место, дата, уровень);
- агрегированные данные для отображения в профиле кандидата.

**Как готовы:**
- интерфейс `FspAdapter` в коде;
- модель данных `fsp.achievements`;
- заглушка возвращает пустой результат;
- при подключении реального API — замена одной реализации без изменений
  в доменной логике.

**Что важно:**
- **Graceful degradation.** Если ФСП недоступен или истории нет — профиль
  работает, показывается нейтральный блок.
- **Rate-limit.** Свой на стороне интеграции + кеш достижений.

## Keycloak / ФСП ID

**Статус:** архитектурно готов, включается флагом.

**Как работает:**
- фронт: `keycloak-js` (уже в `public/app.js`), конфиг из `/api/config`;
- бэк: валидация JWT через JWKS (`jose`), интерфейс `AuthProvider`;
- две реализации: `LocalAuthProvider` (MVP) и `KeycloakAuthProvider` (Post-MVP).

**Переключение:**
```env
AUTH_PROVIDER=local      # или keycloak
KEYCLOAK_URL=...
KEYCLOAK_REALM=fsp
KEYCLOAK_CLIENT_ID=fsp-web
```

## SMTP (e-mail)

**Нужно для:**
- подтверждение регистрации;
- приглашения;
- смена статусов;
- восстановление пароля.

**Провайдеры:** SendGrid / Mailgun / Yandex Cloud Postbox.

**Как устроено:** через Notification Service, очередь с ретраями.
Важные письма дублируются в in-app.

## S3 (файлы)

**Нужно для:**
- PDF-резюме;
- аватарки;
- сгенерированные PDF-профили.

**Dev:** MinIO в compose.
**Prod:** Yandex Object Storage.

## ATS (Post-MVP)

**Цель:** синхронизация статусов с ATS работодателя.

**Планируемые коннекторы:** Huntflow, Greenhouse.

**Механика:**
- Webhook в ATS при событии (`invitation.sent`, `invitation.accepted`);
- REST-коннекторы с OAuth;
- двусторонняя синхронизация статусов;
- маппинг полей.
