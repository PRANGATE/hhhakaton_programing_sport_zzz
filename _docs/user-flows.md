# Пользовательские сценарии

## Кандидат: путь до категории

```
Регистрация (e-mail + пароль)
   ↓
Подтверждение e-mail
   ↓
Заполнение профиля (ФИО, контакты, стек)
   ↓
Опрос: отрасль → специализация → предполагаемый грейд
   ↓
Тест: 5–7 заданий, сгенерированных LLM под профиль
   ↓
Оценка, присвоение категории (например, «Backend · Middle»)
   ↓
Кабинет: категория, история, кнопки «Пройти выше/ниже» (с блокировкой)
```

## Кандидат: получение приглашения

```
Работодатель нашёл категорию «Backend · Middle»
   ↓
Просмотрел профили, выбрал кандидата
   ↓
Отправил приглашение с вилкой зарплаты
   ↓
Кандидат получает уведомление (e-mail + in-app)
   ↓
Открывает приглашение → статус viewed
   ↓
Принимает или отклоняет
   ↓
При accepted: контакты раскрыты, доступен чат
```

## Работодатель: подбор кандидатов

```
Регистрация → профиль компании
   ↓
Описание потребности: свободный текст или форма
   ↓
ИИ разбирает запрос в структурированный фильтр
   ↓
Matching находит кандидатов по категориям
   ↓
LLM ранжирует топ-N с объяснением
   ↓
Просмотр карточки кандидата (без контактов!)
   ↓
Отправка приглашения с описанием и вилкой зарплаты
   ↓
Отслеживание статусов: sent → viewed → accepted/rejected
```

## Сквозной сценарий для демо (60–90 сек)

```
[0:00] Регистрация кандидата (быстро, e-mail)
[0:10] Опрос: Backend → Middle
[0:20] Тест: 3 задания, показываем РАЗНЫЕ у кандидатов
[0:35] Категория присвоена: «Backend · Middle», score 78%
[0:40] Переключаемся на работодателя
[0:45] Вводит свободный текст: «нужен бэкендер на Go, средний»
[0:50] ИИ разобрал запрос, показал фильтр
[0:55] Подборка: топ-5 кандидатов с объяснением
[1:00] Работодатель открывает карточку → контактов нет
[1:05] Отправляет приглашение с вилкой 250–350к
[1:10] Переключаемся на кандидата → видит приглашение
[1:15] Принимает → контакты раскрыты
[1:20] Готово
```

## Дополнительный сценарий: кандидат без истории ФСП

Показываем отдельно, потому что это обязательное требование ТЗ:

1. Кандидат регистрируется, привязки к ФСП нет.
2. В профиле — нейтральный блок: «ФСП ID не привязан», кнопка «Привязать».
3. Работодатель видит профиль, блок достижений ФСП — пустой с пояснением.
4. Категория и приглашения работают как обычно.
