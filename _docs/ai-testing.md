# ИИ в тестировании

Как генерируем и оцениваем тесты. Главный вызов — сопоставимость.

## Проблема из ТЗ

> «Единый набор заданий расходится между кандидатами, генерация нейросетью
> не гарантирует сопоставимую сложность и объективность оценки».

## Решение

### 1. Генерация

- На вход: `(специализация, грейд, тема, сложность)`.
- LLM возвращает структурированный JSON: текст задачи, варианты / поле
  для свободного ответа, рубрика.
- Ограничение: фиксированный набор тем, фиксированные уровни сложности.

### 2. Якорные задачи

- Пул из ~30 эталонных заданий, откалиброванных экспертом.
- Каждое новое сгенерированное задание проходит проверку
  LLM-difficulty-classifier: к какому уровню ближе.
- Если расхождение с заявленным грейдом > X — задание отбрасывается.

### 3. Оценка по рубрике

- Оценка идёт по критериям: корректность, полнота, алгоритмическая сложность.
- Возврат: `{ score: 0–100, breakdown: [...], feedback }`.
- Рубрика фиксирована для задания, а не генерируется заново под каждый ответ.

### 4. Double-check для спорных

- Если score в зоне 40–60% — второй прогон на другой модели
  или self-consistency (несколько прогонов, медиана).
- Даёт устойчивость к «фантазиям» одной модели.

### 5. Итоговый балл

- Агрегация по заданиям с весами (сложность × критерий).
- Балл → попадание в диапазон грейда.
- Грейд не понижается принудительно: кандидат сам решает, идти ниже или
  пересдавать через N месяцев.

## Ограничение смены грейда

- Не чаще одного раза в 90 дней (`test.grade_history.changed_at`).
- Кнопки «Пройти тест выше/ниже» блокируются с датой, когда доступ
  откроется.

## Валидация механики

- **Дискриминативность.** Считаем индекс Джини по результатам пилота.
  Задания с низким индексом — исключаем.
- **Стабильность.** Тест-ретест: один и тот же кандидат при повторном
  прохождении должен получать грейд ±1.
- **Устойчивость.** Задания генерируются уникально; якорные — закрыты.
  Логируем все выданные задания, чтобы можно было оценить распространение.

## Fallback

Если AI Service недоступен:

- задания берутся из заранее подготовленного пула эталонных;
- оценка — по ключам (для вариантов с выбором) или по рубрике вручную.
